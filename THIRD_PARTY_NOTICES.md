# Fontes e créditos

O desenho dos potes em `assets/jars.js` e o estilo visual em `assets/styles.css` foram adaptados de **Kink Jars**, de **LockedTony**:

- Repositório: https://github.com/LockedTony/kink-jars
- Arquivo original: https://github.com/LockedTony/kink-jars/blob/main/index.html
- SHA do blob consultado: `59e4b7b83924497f05411218d316f8b8941fb2ac`
- Consulta: 22 de outubro de 2026.

A coleção **Romance** mantém os 28 itens de **Romantic Jars**, publicado por **Black Whisker Cult** em https://romance.blackwhiskercult.com/. O HTML público foi consultado em 22 de outubro de 2026. Essa página usa a mesma base de desenho e interface do Kink Jars, com uma lista de itens e títulos diferentes. Não foi localizado um repositório GitHub público desse segundo site.

As traduções, explicações, navegação, separação de respostas e sequência progressiva de transbordamento foram acrescentadas nesta adaptação. Os desenhos são gerados no navegador; não há imagens de potes baixadas de outros servidores.

O repositório original consultado não continha arquivo LICENSE. Esta adaptação mantém a atribuição e não atribui uma licença nova ao código de terceiros.

As fontes Oswald, Nunito e Permanent Marker são distribuídas localmente em `assets/fonts/`, sem carregar servidores de terceiros. Os arquivos originais e as licenças foram obtidos do repositório oficial Google Fonts; a revisão exata está em `assets/fonts/SOURCE.md`. Oswald e Nunito usam a SIL Open Font License 1.1, e Permanent Marker usa a Apache License 2.0. Fontes do sistema são usadas como alternativa.
